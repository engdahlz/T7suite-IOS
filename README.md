# T7suite-iOS

Native iPhone port workbench for Saab Trionic 7, based on the user-provided T7Suite 0.1.59.0 archives.

This repository is being initialized with a source audit, a portable Swift core, tests, and a SwiftUI iOS application. Hardware ECU operations must not be represented as validated until they have been tested with a specified adapter and bench ECU.

The uploaded Windows installer and third-party DLLs are not redistributed here. See the forthcoming audit and parity matrix for the exact implementation and verification scope.
